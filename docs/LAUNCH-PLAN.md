# Audience and launch plan

Planning only. No invitation, announcement, advertising purchase or release is authorized by this document.

## Positioning

Working message: **Move your data. See what arrived and what still connects.**

Lead with one supported transfer job and a concrete report, not a universal framework or an AI platform. Existing relationship checks belong in the first supported workflow; assisted new-relationship mapping is a separately labelled later feature.

## Sequence

| Phase | Work | Exit |
| --- | --- | --- |
| Private preparation | Confirm workflow/profile, build harmless examples, repair first-use problems, prepare unsent copy. | Exact package ready for maintainer testing. |
| Personal trial | Maintainer uses the package without hidden operator assistance. | Recorded approval of that candidate and disclosed limits. |
| Small opt-in pilot | Friendly UX checks plus actual-workflow users; document all attempts. | Useful results and repeat/referral intent, not just praise. |
| Bounded public beta | Release one supported slice with example, report, installation and exclusions. | Users can perform the job without bespoke help. |
| Maintain and expand | Fix observed friction, accept fixtures/docs, add profiles from demonstrated demand. | Evidence-backed expansion, not a connector-count target. |

No calendar launch date until the release gate is met. Public repository planning is not a product-launch announcement. Initial paid-advertising budget: zero proposed; no spend is required or approved here.

## Materials

Prepare one README/product page, one short demonstration of a healthy and deliberately altered transfer, a synthetic sample, a readable sample report, supported-format matrix, limitations, installation instructions, and optional feedback questions. Label constructed defects as constructed. Do not publish private filenames, screenshots or testimonials without permission.

The demo should include an equal-count failure and a broken/wrong-target relationship so the value is more than counting files. Offer an inspectable example without mandatory signup. Claim local/no-network behavior only after it is tested in the delivered route; installation traffic is disclosed separately.

## Channels

Start in the selected workflow's own community. Check its current promotion and AI-content rules before posting. Offer a useful method/example, identify maintainer affiliation, and acknowledge native alternatives. Seek collaboration with relevant importers through a concrete fixture or check rather than advertising in their issue tracker.

Personal professional channels can explain the build and request a specific referral. Keep specialist QA and general migration messages separate. Larger launch channels come after a usable release. Do not solicit upvotes, manufacture reviews, send repeated unsolicited messages or treat membership as consent.

Reference principles: [GitHub Open Source Guides: finding users](https://opensource.guide/finding-users/), [welcoming communities](https://opensource.guide/building-community/), and [Show HN requirements](https://news.ycombinator.com/showhn.html). Recheck channel rules at execution time.

## Measurement

An activated user completes an admitted comparison and understands its result. Track attempts, completions, failures, operator interventions, actionable findings or useful clean results, total effort, and continuation/referral behavior. Downloads and stars are secondary discovery indicators. An occasional migration tool need not have daily retention.

Keep early feedback manual and optional. No raw content, filenames, hashes or contact identities in public analytics. The public issue queue records product lessons; private relationship records retain individual recruitment state.

## Working name

TransferGuard describes the aim, but an unrelated [existing file-transfer service](https://transferguard.eu/en) already uses the name (observed 2026-10-20). Keep it provisional and decide a more distinct public identity before broad promotion. This is not a trademark-clearance result. Do not rename the repository, buy domains or reserve paid services automatically.
