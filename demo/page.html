For agents and scripts

The companion package contains a dependency-free Node CLI and an agent skill. Start with node demo/cli.cjs describe. It returns commands, read/write effects, limits, and exit codes as JSON. Write operations require a matching preview-plan token; that token is not proof of human consent.

This page and the CLI share the same comparison engine. The HTML file alone does not contain the CLI.

Working name. No account, remote assets, model calls, or automatic uploads in this demo. Browser comparisons happen in memory. Only your explicit download actions request files. Keep your originals.
